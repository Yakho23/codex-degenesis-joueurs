# Codex Degenesis – version joueur

Aide de jeu pour téléphone : fiche de personnage, lore, règles, Bazar, dés.

Installation : ouvrir le site dans Chrome sur Android → menu ⋮ → **Installer l'application**. Fonctionne ensuite hors ligne.

Outil fait par un fan pour usage personnel. Degenesis est une marque de SIXMOREVODKA ; les illustrations, la police et les textes de règles leur appartiennent.
